# First-party inference development

Production builds currently select `UnconfiguredModelProvider`; Sage cannot yet complete model-backed tasks. The obsolete hosted-provider transport, credential adapter, SSE response parser, and generic speech/vision provider hooks have been removed. New product inference must use Sage-owned code and signed local weights. Do not add hosted model requests, third-party inference runtimes, or agent frameworks.

The model boundary in `crates/sage-core/src/model.rs` remains an untrusted-planning contract. The first-party structured-output schema and parser are Sage-owned code; generated identities and provenance are assigned locally. A generation returns either an answer or a bounded proposal. It cannot mint grants, weaken verification, install policy, or treat recalled content as authority. Every proposed operation still passes current target resolution, policy, permission, expiring capability, execution, fresh verification, and durable result handling.

Implement the local stack in reviewable layers: exact tokenizer and prompt format; scalar CPU reference operators; architecture-specific recurrent and attention state; persistent in-process generation; then optimized CPU and Metal kernels. Compare each optimized path numerically against the CPU reference. Keep model-package signature checks, numerical checks, task-quality evaluation, memory/latency qualification, and device evidence as separate admission gates.

Text, vision, speech, and interface discovery must retain explicit privacy and data boundaries. Apple speech and native OS interfaces may provide platform primitives; Sage owns phrase matching, control policy, evidence handling, planning, and execution. Settings never imply permission to release task content to another process or service.
