# Contextual reviewed-branch proposals, 6 October 2026

This checkpoint adds a local, advisory proposal to the typed composer preview. When a request explicitly refers to a current selection, page, file, window or application, Sage checks whether reviewed branch families are available, captures only that requested foreground reference, and compares its bounded text with the branch request and step terms. Negated actions and mismatched native/browser reference types fail closed. Page text is requested only for an explicit page reference. The raw reference is used in memory and is neither persisted nor sent to a planner.

The result contains no more than two reviewed request aliases. The card labels them “Possible learned paths”; its buttons only fill the composer. The user must still send, and normal task, resource, policy, approval and verification checks apply. The initial grammar preview is delivered first; reference capture and scoring run as a best-effort preview with a two-second deadline. This slice adds no model, inference API, downloaded weights, provider, service or dependency.

`prediction-latency.txt` measures the optimized lexical scoring function across 120 synthetic reviewed families (the pairwise upper bound derived from the existing 16-routine limit) with a 7.5 KiB reference, over 1,000 samples. It excludes SQLite family loading, adapter capture, socket IPC, native UI rendering and user-perceived latency. It is not an end-to-end or live-adapter measurement.
