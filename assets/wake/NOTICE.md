# Bundled wake components

The bundled local keyword spotter uses Apache-2.0 components:

- `sherpa-onnx` runtime: https://github.com/k2-fsa/sherpa-onnx
- GigaSpeech Zipformer KWS model assets: https://www.modelscope.cn/pkufool/sherpa-onnx-kws-zipformer-gigaspeech-3.3M-2024-01-01
- `@sctg/sentencepiece-js` tokenizer runtime: https://www.npmjs.com/package/@sctg/sentencepiece-js

The license text is included in `LICENSE`. Model provenance is retained in `MODEL.md`.
